# Norske forhold

**Hvem denne delen er for:** ledelsen, arkitekten og personvernombudet. Microsofts og GitHubs veiledninger er skrevet for et globalt publikum. Denne delen legger til det som gjelder særskilt for en virksomhet i Norge: rollen under EU AI Act, GDPR og EU-datagrensen, hensyn i offentlig sektor, og hvordan vi skriver om alt dette på norsk uten å oversette produktnavn.

| Side | Svarer på |
|---|---|
| [EU AI Act, rollen som deployer](eu-ai-act-rolle.md) | Hva virksomheten er under forordningen når den bruker Copilot og bygger apper med AI-hjelp, hvilke artikler som gjelder, og fra når |
| [GDPR og EU-datagrense](gdpr-og-eu-datagrense.md) | Hvor kode, prompter og appdata behandles, hvilke tjenester som er innenfor EU Data Boundary og hvilke som ikke er det, og spørsmålene til Microsoft og GitHub |
| [Offentlig sektor](offentlig-sektor.md) | Hensyn for statlige og kommunale virksomheter, med referanser som er merket til verifisering til de er hentet |
| [Språkpolicy](sprakpolicy.md) | Norsk prosa, engelske termer, og hvorfor |

Norge er ikke medlem av EU, men EU AI Act og GDPR gjelder gjennom EØS-avtalen, og de fleste norske virksomheter behandler data om EU-borgere uansett. Les sidene som om forordningene gjelder, og la juristene bekrefte detaljene for din virksomhet.
