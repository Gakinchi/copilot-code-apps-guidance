# Start her

Veiledningen har tre lesestier, én per rolle. Hver sti er en kort liste over sidene du bør lese i rekkefølge, med én setning om hva du sitter igjen med. Du kan lese alt, men du trenger ikke.

| Sti | Les hvis du | Tid |
|---|---|---|
| [For ledelsen](leder.md) | eier beslutningen, budsjettet eller risikoen | 20 minutter |
| [For arkitekten og CoE](arkitekt.md) | skal lede innføringen og sette opp styringen | 1 time |
| [For utvikleren](utvikler.md) | skal bygge Code Apps med Copilot fra i morgen | 1 time, pluss en lab |

Før stiene ligger to sider alle bør lese: [Produktene, hva er hva](produktene.md), fordi navnene forvirrer, og [Seks måter å bygge en app](seks-mater.md), fordi Code Apps er ett av flere valg og du bør vite når det er det riktige.
