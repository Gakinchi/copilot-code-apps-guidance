# Lesesti for ledelsen

**Hvem denne siden er for:** deg som skal beslutte om virksomheten skal ta i bruk GitHub Copilot sammen med Power Apps Code Apps, og som eier budsjettet, risikoen og forventningene. Du trenger ikke kunne verktøyene. Du trenger å vite hva du sier ja til.

## Det du beslutter

Innføringen handler om fem beslutninger, og resten av stien gir deg grunnlaget for hver av dem.

1. **Hvorfor:** hvilket problem løser kombinasjonen av Copilot og Code Apps for oss, og hva erstatter den.
2. **Hvem:** hvilke utviklere og team får lisens først, og hvem som er pilotgruppe.
3. **Hva det koster:** Copilot-seter, Power Apps-lisenser eller forbruksbasert betaling, og tiden som går til opplæring.
4. **Hva som kan gå galt:** kode og prompter som forlater virksomheten, hemmeligheter, preview-funksjoner, regulatoriske krav.
5. **Hvordan vi vet at det virker:** hvilke tall vi måler før og etter, og når vi vurderer piloten.

## Det du ikke trenger å lese

Arbeidsflyt, drift og verktøykasse er for arkitekten og utviklerne. Hvis noen i møtet bruker ord som «environment group» eller «connection reference», er svaret at [arkitekten](arkitekt.md) eier det.

## Neste steg

Når stien er lest: be arkitekten om en [modenhetsvurdering](../planlegg/modenhetsvurdering.md) av dagens situasjon og et forslag til [pilotgruppe](../planlegg/pilotgruppe.md). Det er det første konkrete leveransepunktet i planen.
