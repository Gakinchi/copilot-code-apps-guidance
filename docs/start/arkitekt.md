# Lesesti for arkitekten og CoE-lederen

**Hvem denne siden er for:** deg som skal lede innføringen i praksis: løsningsarkitekten, lederen for Center of Excellence, eller Power Platform-administratoren som har fått ansvaret. Du kjenner Power Platform. Det nye er GitHub Copilot som verktøy i utviklernes hverdag, og Code Apps som apptype med sine egne regler for lisens, miljøer og DLP.

## Det du leverer

Innføringen har fire leveranser fra deg, og stien er lagt opp etter dem.

1. En **modenhetsvurdering** og en anbefalt pilotgruppe.
2. En **styringsplan** med soner, miljøgrupper, DLP og Copilot-policyer, basert på malene i verktøykassen.
3. En **utrullingsplan** med roller, champions og tidslinje.
4. En **målemodell** som ledelsen kan følge.
