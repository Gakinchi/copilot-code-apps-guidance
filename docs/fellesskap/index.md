# Fellesskap

**Hvem denne delen er for:** CoE-lederen som skal bygge det, og lederen som skal gi folk tid til det. Både Microsoft og GitHub sier det samme om innføring: det som avgjør etter lanseringen, er om det finnes noen å spørre, et sted å spørre, og et sted svarene samles. Fellesskapet er de tre tingene.

| Side | Svarer på |
|---|---|
| [Champions](champions.md) | Hvem de er, hva de gjør, hva de får, og når de rekrutteres |
| [Kanal og wiki](kanal-og-wiki.md) | Stedet å spørre med svar samme dag, og stedet svarene bor |
| [Prompt- og skill-bibliotek](prompt-og-skill-bibliotek.md) | Hvordan det som virker, deles som prompter, skills og instruksjonsfiler |

Tidslinjen: champions rekrutteres 45 dager før lansering, kanalen og wikien åpnes på lanseringsdagen, biblioteket starter med det piloten lagde. [Plan 30-90-180](../strategi/30-90-180.md).
