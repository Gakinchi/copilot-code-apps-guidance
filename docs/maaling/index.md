# Måling

**Hvem denne delen er for:** CoE-lederen som skal samle tallene, og ledelsen som skal lese dem. Delen speiler GitHubs «Measure and demonstrate the impact» og «Measuring the success of a trial», og Microsofts «Observability».

| Side | Svarer på |
|---|---|
| [KPI-ark](kpi-ark.md) | Malen med alle KPI-ene, baseline og mål, klar til å fylles ut |
| [Copilot-metrikker](copilot-metrics.md) | Hva GitHubs usage metrics viser, hva de ikke viser, og hvordan du henter dem |
| [Power Platform-metrikker](power-platform-metrics.md) | Inventar, bruk og lisens fra Power Platform admin center og maker-portalen |
| [Pilotevaluering](pilot-evaluering.md) | Kriteriene for å utvide, justere eller stoppe etter 90 dager |

Definisjonene av KPI-ene står i [KPI-er](../strategi/kpier.md) under Strategi. Denne delen handler om å hente og bruke dem.
