# GitHub Copilot og Power Apps Code Apps: veiledning for innføring

Norwegian adoption guidance for organisations that want to use GitHub Copilot
together with Power Apps Code Apps. Modelled on Microsoft's Power Platform
guidance and GitHub's "Roll out Copilot at scale", written for three readers:
leadership, the architect or CoE lead, and the developer.

Site: https://gakinchi.github.io/copilot-code-apps-guidance/

Build locally:

```bash
pip install -r requirements.txt
mkdocs serve
```

Every page carries a `verifisert:` date and a `kilde:` label. Commands are run
in a lab before they are published. Contributions and corrections are welcome
as issues or pull requests; Norwegian prose, English product terms.

Author: Dennis Chi, [recursion.no](https://recursion.no).
